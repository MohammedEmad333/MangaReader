### What's new
- Treat a successful same-host WebView page load as a usable browser session even when Cloudflare does not issue a `cf_clearance` cookie.
- Detect main-frame HTTP failures and Cloudflare challenge documents before accepting the WebView page.
- Flush the shared WebView cookie store and save that host's native WebView User-Agent before returning to Yomu, so OkHttp retries with the same browser session identity.
- Keep 403/503 responses and visible or text-based challenge pages in WebView rather than treating them as success.

### Validation
- Unit tests cover successful pages without clearance cookies, challenge documents, HTTP errors, and same-host/subdomain checks.
- Build and Android emulator smoke test required before publishing.
- Real-device Asura test must confirm that the successful WebView page returns to Yomu and the chapter list then loads.
