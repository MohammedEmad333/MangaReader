### What's new
- Downloads now shows verified local chapters before the slower legacy folder recovery completes. Internet access is not required.
- Large libraries no longer trigger full chapter-cache recovery when their downloaded folders already have valid identity markers.
- Incomplete queued chapters do not force unnecessary full-library recovery.
- The Downloads screen shows a clear warning and Retry button if a filesystem scan stalls or fails, and warns if the selected storage is unavailable.
- Existing saved files are not deleted by these checks.

### Validation
- JVM regression tests cover verified local download records and complete versus incomplete legacy folders.
- The Android emulator workflow validates application launch and instrumentation when downloads code changes.
