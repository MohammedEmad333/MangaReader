### What's new
- Remove the manual Done bypass from the Cloudflare WebView. A manual tap can no longer claim that verification passed when no clearance cookie exists.
- Show a live waiting/received status based on the presence of the `cf_clearance` cookie.
- Automatically return to the active series only after the cookie is present, flushed, and its matching WebView User-Agent is recorded.
- Add a Reload page action for a page that loads but does not display a verification widget.

### Validation
- Unit tests verify the 0.337 release note.
- Build and Android emulator smoke test required before publishing.
- Real-device test must verify that the challenge widget is visible, a real clearance cookie is issued, and chapter loading succeeds.
