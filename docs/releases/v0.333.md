### What's new
- Load series metadata and chapters through one combined extension request when supported. This avoids repeating the same Asura Scans series-page request for details and chapter listing.
- Preserve the legacy details/chapter path for older extensions.
- Apply the combined result when opening and refreshing a series, while preserving cached chapter fallback for offline Library, Downloads, and History access.

### Validation
- Build and JVM tests are required before merge.
- Real-device Asura Scans chapter-list and chapter-page validation is still required after installing the build.
