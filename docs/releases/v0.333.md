### What's new
- Load series metadata and chapters through one combined extension request when supported. This avoids repeating the same Asura Scans series-page request when opening or refreshing a series.
- Preserve the legacy details/chapter path for older extensions.
- Keep the existing library metadata enrichment and cached chapter fallback behavior unchanged.

### Validation
- Build and JVM tests are required before merge.
- Real-device Asura Scans chapter-list and chapter-page validation is still required after installing the build.
