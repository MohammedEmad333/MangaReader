### What's new
- Share Cloudflare's per-host retry cooldown across the OkHttp interceptor and visible WebView recovery.
- Clear the cooldown when the visible WebView confirms the protected page loaded, before the series reload starts.
- Prevent a stale 60-second cooldown from rejecting the immediate chapter retry after a successful WebView visit.

### Validation
- Unit tests cover cooldown clearing across separate instances.
- Build and Android emulator smoke test required before publishing.
- Real-device validation must confirm that WebView returns to Yomu and the chapter request is actually sent and succeeds.
