### What's new
- Re-resolve the selected download location when opening Downloads or tapping Retry. Reconnecting an SD card or restoring folder permissions no longer requires a process restart to re-check the path.
- Keep the local-only first view for already downloaded chapters introduced in 0.331.
- Add an Android emulator regression that reads a locally saved chapter from disk without HTTP access, then confirms that losing its page removes the chapter from the complete-download list.

### Validation
- JVM unit suite and Android emulator instrumentation are required before merge.
- A physical-device airplane-mode test with an existing real download library remains important.
