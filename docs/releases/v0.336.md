### What's new
- When Cloudflare blocks a series, Open in WebView now opens that exact manga URL instead of the source homepage. This matters for sites where the homepage is public but manga pages are protected.
- After the visible challenge is completed and cf_clearance is stored with the WebView's User-Agent, Yomu automatically retries the active series.
- Connection probe stops after a confirmed series-page challenge instead of waiting through a duplicate request to the same blocked URL.
- The diagnostic combined-fetch timeout now leaves enough room for the Cloudflare interceptor's own challenge attempt to finish and return its original HTTP error.

### Validation
- Unit tests cover exact-series URL preference and homepage fallback.
- Build and Android emulator smoke test required before release.
- Real-device validation must confirm that the WebView challenge can be completed and the series chapter list then loads.
