### What's new
- Last-read library sorting now builds the recency index in one pass without allocating temporary groups of chapter history.
- Multiple history chapters for the same source and series still select the newest reading timestamp.
- Identical series IDs from separate sources are kept distinct, while standalone files with missing IDs do not enter the library sort index.

### Validation
- JVM regression tests verify latest timestamps, source-qualified series IDs, missing IDs, empty input and minimum timestamps.
- The Android emulator workflow exercises install, launch and instrumentation on this change.
