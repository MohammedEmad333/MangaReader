### What's new
- Serialize combined manga updates through the same per-series lock used by details-only and chapter-list calls.
- Prevent a combined Asura Scans request from overlapping a library refresh, metadata lookup, or chapter-list request for the same manga.
- Keep different manga independent so they can still load concurrently.

### Validation
- JVM regression tests exercise combined updates concurrently with details-only and chapters-only calls, and confirm that different manga are not unnecessarily serialized.
- Android emulator smoke test and a real-device Asura Scans chapter/page test are required before calling the issue resolved.
