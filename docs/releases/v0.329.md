### What's new
- Library search now normalizes query terms once per arrangement and reuses them across all source and category groups.
- Unicode separator and Arabic/diacritic normalization patterns are compiled once rather than recreated during each title comparison.
- Arabic alef variants, ya/alif-maqsura, tatweel, accent-insensitive matching, word-order independence and partial matches are preserved.

### Validation
- JVM tests cover Arabic and Latin normalization, word order, partial matches, reusable compiled queries and empty Unicode-space queries.
- Android emulator smoke validates application install and launch on the merged build.
