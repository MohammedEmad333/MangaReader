# SeriesHub extension repository

This directory publishes the SeriesHub anime/video extensions in the flat Aniyomi-compatible format that Yomu already supports.

## Add to Yomu

Open **More → Browse → Extension repos** and add:

`https://raw.githubusercontent.com/MohammedEmad333/MangaReader/main/repo/index.min.json`

Then open **Browse → Extensions → Anime** and install the SeriesHub sources you want.

Legacy descriptor URL:

`https://raw.githubusercontent.com/MohammedEmad333/MangaReader/main/repo/repo.json`

## Current extensions

- Cima4u 17.6
- DramaCafe 17.4
- WatanFlix 17.5

Each entry points to the matching APK asset on the rolling `latest` prerelease tag.
