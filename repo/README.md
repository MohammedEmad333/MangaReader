# SeriesHub extension repository

This directory exposes the SeriesHub anime/video extensions in the flat Aniyomi/Tachiyomi-compatible repository format that Yomu already understands.

## Repository URL

Use the raw `index.min.json` URL in **Yomu → More → Browse → Extension repos**:

`https://raw.githubusercontent.com/MohammedEmad333/MangaReader/main/repo/index.min.json`

Legacy clients that accept a descriptor URL may use:

`https://raw.githubusercontent.com/MohammedEmad333/MangaReader/main/repo/repo.json`

## Published sources

- Cima4u 17.2
